# Лабораторная работа №5 - DOM и взаимодействие с элементами страницы

## Тема работы

Манипулирование DOM-деревом, нахождение элементов, изменение их содержимого и стилей, а также сохранение состояния страницы между перезагрузками через `localStorage`.

## Вариант 2 - "Путешественник"

В рамках текущей лабораторной работы на страницу добавлен редактируемый список навыков, позволяющий пользователю самостоятельно добавлять новые и удалять уже имеющиеся.

Реализованы следующие операции с редактируемым списков навыков:
* добавление нового навыка с запросом его названия через `prompt` (также обрабатываются случаи отмены ввода и пустых значений);
* удаление отдельного навыка;
* полная очистка списка навыков (если список уже пуст, выводится предупреждение через `alert`);
* скрытие и отображение списка навыков.

Список навыков сохраняется в `localStorage`, благодаря чему ранее добавленные пользователем элементы не теряются после перезагрузки страницы. Также в `localStorage` хранится состояние скрытости редактируемого списка навыков.

Дополнительно реализовано переключение между светлой и тёмной темами оформления сайта. Для тёмной темы были продублированы все имеющиеся CSS-переменные с цветами. Выбранная тема, опять же, сохраняется в `localStorage` и восстанавливается при повторном открытии страницы.

## Нововведения

Проект манипулирует содержимым HTML-страницы с использованием следующих возможностей JavaScript:

* DOM (Document Object Model) для взаимодействия с HTML-элементами страницы;
* `getElementById` для поиска элементов по идентификатору;
* `querySelector` и `querySelectorAll` для поиска элементов по CSS-селекторам;
* `createElement` для создания новых HTML-элементов;
* `appendChild` для добавления элементов в DOM;
* `remove` для удаления элементов из DOM;
* `textContent` для изменения текстового содержимого HTML-элементов;
* `classList.toggle`, `classList.contains` и `classList.add` для управления CSS-классами элементов;
* `addEventListener` для обработки пользовательских событий;
* `localStorage.setItem` и `localStorage.getItem` для сохранения и получения данных;
* `JSON.stringify` и `JSON.parse` для преобразования массива навыков в строку и обратно;

В результате преимущественно доработан файл `script.js`, обеспечивающий взаимодействие пользователя с элементами страницы (в частности, с редактируемым списков навыков) в соответствии с ТЗ и требованиями моего варианта.

В работе продемонстрированы основные возможности DOM API, обработка пользовательских событий, динамическое создание и удаление HTML-элементов, управление CSS-классами, переключение тем оформления и сохранение данных с помощью `localStorage`.
